## 🚀 الملفات المطلوبة للرفع على GitHub

عند رفع المشروع على مستودع GitHub، يتم رفع محتويات هذا المجلد:
1. `index.html` (الصفحة الرئيسية للمنصة)
2. `styles.css` (أنماط المنصة والألوان ومعاينة A4)
3. `app.js` (منطق التفاعل واستوديو الانفوجرافيك والتصدير)
4. `.nojekyll` (ملف ضروري لعمل GitHub Pages بسلاسة)
5. `.gitignore` (استثناء الملفات غير اللازمة)
6. `README.md` (دليل المنصة)
7. مجلد `assets/` (يحتوي على الـ 19 فريماً مرجعياً للانفوجرافيك وملف الكتالوج)

---

## ⚡ خطوات النشر في دقيقتين على GitHub Pages

1. ادخل على **[GitHub.com](https://github.com)** وأنشئ مستودعاً جديداً باسم: `raqeem-studio`.
2. اجعل المستودع **Public** واضغط **Create repository**.
3. اضغط على رابط **"uploading an existing file"**.
4. اسحب وأفلت الملفات الستة بالإضافة لمجلد `assets`، ثم اضغط **Commit changes**.
5. من إعدادات المستودع (**Settings**) -> اختر **Pages** -> ومن خيار **Branch** اختر `main` واضغط **Save**.
6. سيظهر لك رابط موقعك المباشر في ثوانٍ:  
   `https://<username>.github.io/raqeem-studio/` 🎉
